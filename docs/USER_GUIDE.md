# User guide

1. Start with `python main.py`.
2. Dashboard shows real SQLite counts (empty until you add data).
3. AI Providers: add a provider, paste key (Windows DPAPI), Test connection.
4. Event Planner: create calendar, generate with AI, review, approve.
5. Event Calendar: three months, Calendar/List views.
6. Content Studio: generate then Save as draft.
7. Posts: draft → pending → approve → schedule. Publishing needs OAuth.
8. Database page: backup/restore.
